What this system is

The Task Board is the shared place where Param work is listed, updated, reviewed, and closed.

It stays in sync with your Google Sheets. Day to day, people work in the website — not by typing into every sheet cell by hand.

Who can do what

RoleTypical use
Team memberOwn work, updates, file links, submit for review
Moderator / leadReview files, approve finished work, help across people
AdminEverything above, plus Inject, project updates, reassign, delete

On the live site, your password comes from the Master spreadsheet users list. Training/demo passwords from a local practice machine are not live passwords unless that person also exists on the Master users list.

Getting in

  1. Open the Task Board website.
  2. Click Log in.
  3. Enter username and password.
  4. Click Sign in.

When finished, use Log out.

If login fails: check Caps Lock, then confirm your row still exists on the Master users sheet and the password matches.

Admins also see Update projects in the top bar after signing in.

Managing projects

Projects are the buckets people pick when creating work (for example Social Media or a grant name).

Where the list lives

On the Master Google Sheet, open the admin tab.

ChangeResult on the website
Set Active to NoProject disappears from the dropdown (row can stay on the sheet)
Set Active to YesProject appears again
Edit Pseudo Name (column F)That friendly name is what people see in the dropdown
Reorder rowsChanges the order of the list

If Active keeps jumping back to Yes, the cell still has a formula. Replace it with plain text No or Yes. Google may warn that the area is protected — choose OK if you are allowed to edit.

After you change the sheet

  1. Save the Google Sheet.
  2. On the website (as admin), click Update projects.
  3. Open + Add task and confirm the list.

The list also refreshes by itself within a short time. The button is for “I need it right now.”

Do not casually edit the Project code formula columns. Wrong codes break how new work IDs are created.

Creating and editing tasks

Create

  1. Go to Board.
  2. Click + Add task.
  3. Choose a Project (required).
  4. Enter a clear Name (and notes if useful).
  5. Click SUBMIT.

The system assigns the official ID in the background — you never type that ID.

Edit

Open a card → EDIT → change fields → UPDATE.

Admins can also reassign people, change status, or delete a task when needed.

Links, review, and approval

People can add up to four review links on a task (Add link). Each needs a name and a working URL.

Reviewers use Needs attention and the card’s Review / Submit Feedback tools.

StarsSimple meaning
3★Approved
2★Acceptable with a tag
1★Needs rework (comment required)

Approving finished work

When main work is Done, it may show Waiting for approval.

  1. Open Needs attention.
  2. Focus Waiting approval if helpful.
  3. Click Approve task — or select several and use Approve tasks.

Bulk Inject (admins)

Use Inject when you have a list from chat or a spreadsheet export.

  1. Paste into Bulk text.
  2. Click Process.
  3. Filter and select the rows you want.
  4. Set Project / Kind if needed → Apply to selected.
  5. Click Inject into system.

Unmapped projects must be chosen from the Master list before inject. Prefer fixing the Master project list and clicking Update projects first.

Everyday checklist

  • Board loads and people can log in
  • Project list matches what you want (Active + Pseudo Name)
  • Needs attention is cleared or assigned
  • After Master sheet project edits → Update projects → spot-check + Add task

Things to avoid

  • Editing Task IDs in Google Sheets by hand
  • Running an old writing system and this board against the same sheets at the same time
  • Inventing projects only on a personal sheet instead of the Master admin tab
  • Leaving Active stuck as an auto-Yes formula so you cannot turn projects off
  • Expecting offline demo logins to work on the live website
